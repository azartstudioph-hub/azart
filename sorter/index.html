Сортування фото

Інструмент бере замовлення з сайту, знаходить фото за назвою файлу й розкладає їх копії по папках груп, замовників і друку. Оригінали не змінюються.

Цей інструмент працює лише в браузері Chrome або Edge на комп'ютері. У вашому браузері вибір папок недоступний.

1Підключення до сайту

Дані беруться з вашого сайту AZART. Потрібен пароль адміністратора (той самий, що для сторінки «Адміністратор»).

Папки груп у папці з фото (необов'язково)

Якщо в різних групах є різні фото з однаковими назвами, вкажіть, у якій папці лежать фото кожної групи. За замовчуванням папка визначається за назвою групи (наприклад, «Група 8» або «8»). Якщо файл не вдається визначити однозначно, він не копіюється й потрапляє в конфлікти.
