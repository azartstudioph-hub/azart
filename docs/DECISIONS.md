# Що змінилось порівняно з Wix, прийняті рішення та відкриті питання

Документ для вас і для того, хто підтримуватиме сайт далі. Тут зібрано все, що я вирішив самостійно або де нова версія поводиться інакше, ніж Wix.

## 1. Що перенесено без змін по суті

- Усі сторінки з відеозаписів: вибір садочка → бланки → групи → галерея → форма → «Замовлення оформлене»; перегляд замовлень бланка й групи; сторінка одного замовлення; друк; адмін-панель із бланками; редактор бланка (звичайний і портретний), діапазони типів, налаштування цін, видалення бланка.
- Розрахунок цін перевірено на відповідність коду Wix (Velo) окремими тестами: подарунок, відсоткові знижки (три рівні), ціна «Вся фотосесія», доплата «друк + електронні».
- Сортувальник папок для друку: правила вибору файлів і назв залишились як були. Змінилось лише підключення (замість Wix-ключа він входить у ваш сервер за паролем адміністратора).
- Кольори, шрифт Montserrat, структура екранів за скріншотами. Додано українську та англійську мови, світлу й темну теми.

## 2. Відмінності в поведінці

| Тема | Нова версія |
|---|---|
| Режими | У Wix один параметр `mode` (photographer / client) означав різні речі на різних сторінках. Тут три явні наміри: створити замовлення, переглянути замовлення, адміністрування. Адмінські можливості (сума бланка, друк, статуси, видалення) доступні **лише після входу за паролем** |
| Кінцева дата | Wix порівнював північ кінцевої дати з поточним часом, тож у сам день дедлайну бланк уже вважався закритим. Тут бланк відкритий **до кінця дня кінцевої дати** (за київським часом) |
| Після кінцевої дати | Фото й замовлення можна дивитись; форма відправки заблокована для всіх, крім адміністратора. У «Параметрах сайту» можна дозволити прийом і після дати |
| Приватність | Телефон і коментар у публічних списках приховані. Їх бачить адміністратор і власник замовлення за посиланням із секретним ключем. Імена можна скоротити («Іваненко О.») |
| Суми | Остаточну суму рахує **сервер**: значення з браузера йому не довіряють. Повторне натискання «Відправити» не створює дубль замовлення |
| Вибір у галереї | Зберігається в браузері одразу (чернетка живе 60 хв, налаштовується) і синхронізується з формою |
| Кількість у формі | Лічильник позицій рахує лише заповнені рядки; порожні рядки при відправці відкидаються |
| «Вся фотосесія» | Галочка є лише в портретних бланках і лише коли ціна фотосесії більша за 0 |
| Помилка типу | Не обраний тип підсвічується |
| Форма закритого бланка | Недоступна для клієнтів; адміністратор може створювати замовлення завжди |

## 3. Додано для зручності

- Друк: перемикач коментарів; формат A4.
- Замовлення: видалення (з підтвердженням), стрічка номерів фото для пошуку, статуси з кольоровими мітками.
- Список замовлень: пошук за іменем (якщо їх багато).
- Бланк: перевірка папки Google Диска, перевірка унікальності назви, зрозумілі помилки діапазонів.
- Імпорт із Wix (`import.html`), перенесення фото груп у ваш Google Диск, ідемпотентний повторний імпорт.
- `404.html`, `.nojekyll`, відносні посилання (сайт працює в підпапці GitHub Pages і на власному домені).

## 4. Обмеження та особливості

- **Один пароль адміністратора** (властивість `ADMIN_PASSWORD`). Окремих акаунтів немає. Якщо потрібно кілька людей з різними правами, це окрема доробка.
- **Захист від підбору пароля глобальний**: Apps Script не бачить IP, тому після 10 помилок за 10 хвилин вхід блокується для всіх, включно з вами.
- **Папки з фото мають бути відкриті «усім за посиланням»**: Drive API з ключем бачить лише публічні файли. Це відмінність від Wix, де використовувався службовий акаунт.
- **Швидкість сервера**: Apps Script відповідає за 0,5–2 с, інколи довше після простою (холодний старт). У інтерфейсі це показано станами завантаження й повторами.
- **Квоти Google** для Apps Script та Drive API обмежені, але для типового обсягу замовлень вистачає з великим запасом.
- **Сортувальник** працює лише в Chrome/Edge (потрібен доступ до папок на комп'ютері).
- **Порядок рядків у імпортованих замовленнях**: експорт Wix його не зберігає, тому рядки впорядковано за номером фото.
- **Садочок бланка** в експорті Wix відсутній: його вибирають під час імпорту. Прапорець «Подарунок» теж треба перевірити вручну (у Wix він був порожнім).
- Wix зберігав розмір із кириличною «х» (`10х15`), нова версія всередині використовує латинську `10x15`. Для сортувальника експорт повертає кириличну, як раніше.
- Сповіщень (лист, Telegram, SMS) про нові замовлення немає: у наданих матеріалах їх не було. Якщо потрібні, їх легко додати на сервері (Apps Script вміє надсилати листи).

## 5. Що лишилось зробити вам

1. Створити Google-ключ Drive API з обмеженнями (розділ 3 у `SETUP.md`) і вписати його разом з `API_URL` у `assets/js/config.js`.
2. Замінити посилання Telegram у `config.js` на нік, якщо він у вас є.
3. Після імпорту перевірити в кожному бланку: садочок, прапорець «Подарунок», папку Google Диска (кнопка «Перевірити папку»).
4. Замінити (ротація) ключі, які колись потрапляли в чат або скріншоти: старий ключ Drive API та службовий ключ сортувальника `sort_photo_azart`. Нікому не надсилайте `private_key`.
5. Вирішити, чи потрібна індексація сайту пошуковиками (зараз стоїть `noindex`).
6. Не закривати Wix-сайт, доки не завершилось перенесення фото груп.
